# Cell Wall Dynamics and Biomolecular Condensates - Meta-Analysis

## Project Overview
Meta-analysis of previously published data from 2 laboratory publications for inclusion in the review article "Cell Wall Dynamics and Biomolecular Condensates in Plants"

## Directory Structure
- `data/raw/`: Original Excel files from publications
- `data/processed/`: Processed datasets
- `scripts/`: Python scripts migrated from Colab
- `results/figures/`: Output figures
- `results/tables/`: Output tables
- `logs/`: Execution logs
- `notebooks/`: Original Colab notebooks (for reference)

## Environment
- Python 3.10+
- GPU: NVIDIA RTX A5000 (24 GB VRAM)
